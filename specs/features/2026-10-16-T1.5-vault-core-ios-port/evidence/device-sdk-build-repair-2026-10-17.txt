# WHY: the T1.5 device gate needs a device-SDK build (the runbook builds for iphoneos). That build
# failed before compiling vault-core: see workspace-config-checks-2026-10-17.txt, CHECK 2.
#
# BEFORE
#   $ xcodebuild -workspace ios/NexVault.xcworkspace -scheme VaultCore -destination 'generic/platform=iOS' \
#       -skipPackagePluginValidation -skipMacroValidation CODE_SIGNING_ALLOWED=NO build
#   -> exit 65; rsync error: Pods/ReactNativeDependencies/framework/packages/react-native/
#      ReactNativeDependencies.xcframework/ios-arm64/*: (l)stat: No such file or directory
#
# ROOT CAUSE (inspected, not guessed)
# - ReactNativeDependencies.podspec's prepare_command copies the *parent directory* of the extracted
#   xcframework (cp -R "$XCFRAMEWORK_PATH/../." framework/packages/react-native/), so pod install
#   leaves it nested: framework/packages/react-native/third-party/ReactNativeDependencies.xcframework
# - The build phase "[RNDeps] Replace React Native Dependencies for the right configuration, if
#   needed" runs RN's third-party-podspecs/replace_dependencies_version.js, which extracts the
#   configuration's tarball and moves the xcframework up to the expected path - but it
#   short-circuits ("No previous build detected, but Debug Configuration. No need to replace
#   RNDeps") when ReactNativeDependencies/.last_build_configuration is absent and the configuration
#   is Debug, which is exactly the state left by the last pod install.
# - The failure only surfaces when CocoaPods' copy-XCFrameworks phase actually has to run for a
#   slice that is not already in the build products, i.e. the first device (or Release) build;
#   Debug-simulator builds had up-to-date outputs and skipped it.
#
# REPAIR (React Native's own script, run from the Pods root; no repo file touched)
#   $ cd apps/mobile/ios/Pods
#   $ node <react-native>/third-party-podspecs/replace_dependencies_version.js -c Release -r 0.86.3 -p "$PWD"
#   $ node <react-native>/third-party-podspecs/replace_dependencies_version.js -c Debug   -r 0.86.3 -p "$PWD"
#   -> "Done replacing React Native Dependencies" twice; layout becomes
#      framework/packages/react-native/ReactNativeDependencies.xcframework (slices: ios-arm64,
#      ios-arm64_x86_64-simulator, maccatalyst, macos, tvos, xros) and the marker file
#      ReactNativeDependencies/.last_build_configuration = Debug
#
# AFTER
#   $ xcodebuild -workspace ios/NexVault.xcworkspace -scheme VaultCore -destination 'generic/platform=iOS' \
#       -skipPackagePluginValidation -skipMacroValidation CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build
